# All YouTube Video Downloader (AYTD)

A modern, responsive YouTube downloader web application built with Next.js 14, React 18, and Tailwind CSS.

## Features

- **Video & Audio Separation**: Clean tabbed layout for high-resolution video streams and pure audio extracts.
- **YouTube Thumbnail Downloader**: Dedicated tool to extract standard, HQ, and MaxRes YouTube thumbnails.
- **Multi-Language Architecture**: Ready for global audiences with locale routing and translated UI components.
- **45 In-Depth Tech Guides & Blogs**: Over 55,000 words of technical guides, bitrate calculators, FFmpeg workflows, and troubleshooting.
- **AdSense & Legal Compliance**: Full GDPR/CCPA cookie consent banners, Privacy Policy, Terms of Service, DMCA policy, and Contact pages.
- **Dynamic SEO Sitemap**: Automatically generated `sitemap.xml` indexing all tools and articles with canonical tags and Open Graph metadata.
- **Procedural Canvas Generator**: Built-in visual banner generator for rich blog post covers.

## Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **UI Library**: [React 18](https://react.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: TypeScript / Modern JavaScript

## Getting Started

### Prerequisites

- Node.js 18.17 or higher
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Jahangir7861/allyoutubevideodownloader.git
   cd allyoutubevideodownloader
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
npm run build
npm run start
```
